# OpenClaw 全自动增长工作流（中国大陆平台）

## 目标
你只提供账号，系统自动完成：定位、活动匹配、选品、上架、比价、客服、复购、反馈优化。

## 模块
1. `setup_profile`：统一简介、人设、视觉。
2. `scan_market`：抓取关键词热度、竞品价格、活动入口、评论需求词。
3. `publish_product`：生成标题/主图文案/详情页并上架。
4. `enroll_official_campaigns`：仅参加“定位匹配度>=阈值”的官方活动。
5. `auto_reply`：分层客服（咨询/比价/催单/售后）。
6. `after_sales_feedback_loop`：自动收集差评关键词并驱动商品文案改版。

## 蓝海识别规则
蓝海分数 = 0.4*需求 + 0.25*利润 + 0.25*新鲜度 - 0.3*竞争。

筛选条件：
- 近7天需求上升（搜索/询盘）
- 前20商品评价里“未被满足需求”出现频次高
- 竞品同质化文案比例高（可差异化切入）

## 平台流量最大化策略
- 小红书：话题活动 + 搜索关键词占位 + 评论区承接。
- 抖音：短视频前3秒钩子 + 直播切片复用 + 同步商品橱窗。
- 闲鱼：高意图词标题 + 价格阶梯 + 自动议价边界。
- 拼多多：活动报名（类目匹配）+ SKU分层 + 评价引导模板。

## 风控
- 禁用承诺词（如稳赚/包过）。
- 高频动作随机间隔，触发风控即降频或停机。
- 活动报名前做定位相似度检查，避免错投活动。

## 运维节奏
- 每日：运行 `run_daily`。
- 每周：重算蓝海词池，淘汰低转化赛道。
- 每月：汇总利润与复购，自动切换主赛道。
